### Pokedex Flask Application (Estudos/TestsFlask)

PT-BR: Esta é uma aplicação Flask simples que serve como Pokedex, permitindo que os usuários visualizem e pesquisem Pokémon. A aplicação busca dados da PokeAPI e os exibe em uma interface amigável.

ENG: This is a simple Flask application that serves as a Pokedex, allowing users to view and search for Pokémon. The application fetches data from the PokeAPI and displays it in a user-friendly interface.


### Funcionalidades / Features 

- **Listagem de Pokémon**: Exibe uma lista de Pokémon com suas imagens e nomes.
- **Detalhes do Pokémon**: Exibe detalhes como habilidades, tipos e experiência base de cada Pokémon.
- **Localização de Pokémon**: Permite que os usuários pesquisem Pokémon por nome ou ID.
- **Interface Responsiva**: Utiliza Bootstrap para uma interface responsiva e amigável.

### Tecnologias Utilizadas / Technologies Used
- **Flask**: Framework web para Python.
- **Bootstrap**: Framework CSS para design responsivo.
- **PokeAPI**: API pública para dados de Pokémon.


### Instalação / Installation
1. Clone o repositório // Clone the repository:
   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. Instale as dependências // Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Instale as dependencias do Front-end // Install the front-end dependencies:
```bash
   npm install
   ```

4. Execute a aplicação // Run the application:
   ```bash
   python ou python3 run.py
    ```


5. Acesse a aplicação no navegador // Access the application in your browser:

    ```
    http://localhost:5000
    ```
